- [ ] JWT_SECRET 已更换为强随机密钥（非 dev-secret）

- [ ] 所有 API 端点均有认证检查（authMiddleware）

- [ ] XSS 防护已确认（Vue 默认转义 + CSP Header）

## 🚨 紧急回滚

如上线后发现严重问题：

```bash
# 前端回滚：COS 控制台 → 版本管理 → 回滚到上一版本
# 后端回滚：CloudRun 控制台 → 版本管理 → 回滚到上一版本
# 数据库回滚：如需，执行 pg_restore
```
