# 豆豆机制 · 后端字段方案（砸金蛋诞生 + 密码锁涌现 + 由易到难成长）

> 配套 PRD V3.7 第四章（4.2 / 4.3.6 / 4.6）。本文只出方案，改表前需老板确认。
> 遵守三条根系铁律：① 宁可多留字段不改表 ② 接口返回对象不返回裸值 ③ 能写配置不写死代码。

## 一、现状盘点（pets 表已有字段）

| 字段 | 类型 | 说明 | 处理 |
|------|------|------|------|
| birthPlace | varchar(20) | 出生地 | 保留，语义改为"密码锁第一位加权" |
| stage | varchar(10) | 成长阶段，默认 seed | **扩容 length 并改阶段枚举** |
| stageProgress | integer | 阶段内进度 | 保留，复用为孵化/进化条 |
| totalLearningMinutes | integer | 累计学习分钟 | 保留，成长曲线驱动源 |
| personality / specialty | varchar(20) | 性格/特长 | 保留，作密码锁转轮驱动信号 |

pet_evolutions 表（进化历史）已有 fromStage/toStage/totalMinutesAtTrigger，**沿用记录每次晋升**。

## 二、pets 表新增字段

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| container | varchar(20) | null | 砸金蛋选定的容器：egg/roe/seed/cocoon… |
| rarity | varchar(10) | 'common' | 稀有度：common/rare/mythic（只影响外观，不影响学习） |
| hatchProgress | integer | 0 | 孵化进度（学习推进，非时间倒计时），满即破壳 |
| lockSlots | jsonb | '{}' | 密码锁各转轮当前格位，如 {"base":2,"limb":1,"decor":0} |
| lockFinalized | boolean | false | 密码锁是否已全部锁定（终态定格） |
| bornAt | timestamp | null | 破壳时间（命名仪式后写入） |

> stage 枚举更新为：`incubating`(孵化) → `hatched`(破壳) → `juvenile`(幼体) → `growing`(成长期) → `evolving`(进化) → `complete`(终态/圆满)。stage 列 length 需从 10 扩到 16。

## 三、新增表：pet_lottery（砸金蛋记录）

记录每次砸蛋结果，支持"3 次机会 + N 选 1 挑喜欢"，且留痕可追溯。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| userId | uuid | 用户 |
| chanceIndex | integer | 第几次机会（1~3） |
| container | varchar(20) | 砸出的容器 |
| rarity | varchar(10) | 砸出的稀有度 |
| chosen | boolean | 是否被孩子最终选中留下 |
| crackedAt | timestamp | 砸开时间 |

## 四、配置表（不写死代码）

### 4.1 成长曲线配置 growth_curve_config

| stage 晋升 | thresholdMinutes | 额外门槛 |
|------|------|------|
| incubating→hatched | 5 | — |
| hatched→juvenile | 30 | — |
| juvenile→growing | 90 | — |
| growing→evolving | 240 | masteredWords≥30 |
| evolving→complete | 500 | masteredWords≥100 且 specialty 已固化 |

> 起始值，上线后按真实流失数据调，改配置不改代码。

### 4.2 砸蛋概率配置 lottery_config

| rarity | 基础概率 | 出生地加权 |
|------|------|------|
| common | 70% | — |
| rare | 25% | 匹配出生地倾向 +5% |
| mythic | 5% | 匹配出生地倾向 +2% |

> 首次砸蛋保底：第 1 次机会强制 ≥ rare（不给最差）。

### 4.3 密码锁配置 lock_config（MVP 先 2 转轮）

| 槽位 slot | 格数 | 驱动信号 |
|------|------|------|
| base（基底） | 4 | 学习主题分布（海洋/动物/…）+ 出生地加权 |
| limb（附肢） | 3 | 性格 personality |

> MVP：4×3=12 种形态，画 7 张图。验证爽感后加 decor（点缀）等第 3+ 转轮。

## 五、接口返回口径（对象不返回裸值）

### GET /api/pets/mine 返回示例
```json
{
  "pet": {
    "name": "小海",
    "container": "egg",
    "rarity": "rare",
    "stage": "incubating",
    "stageProgress": 0.6,
    "hatchProgress": 0.6,
    "lockSlots": { "base": 2, "limb": 1 },
    "lockFinalized": false
  },
  "growth": {
    "currentStageLabel": "孵化中",
    "nextStageLabel": "破壳",
    "minutesToNext": 2,
    "hookText": "再陪我学 2 分钟，我就要破壳啦"
  }
}
```

### 新增 POST /api/pets/lottery/crack —— 砸一次蛋
入参 `{ chanceIndex }`，返回 `{ container, rarity, remainingChances }`

### 新增 POST /api/pets/lottery/choose —— 定容器
入参 `{ lotteryId }`，把该记录 chosen=true，写入 pets.container/rarity，stage=incubating

## 六、成长引擎接入点（关键）

`POST /api/session/end` 现在只累加 totalLearningMinutes。需追加：
1. 读 growth_curve_config，判断是否达到下一 stage 阈值
2. 达到则推进 stage、写 pet_evolutions、按 lock_config 拨动 lockSlots 转轮（+微随机）
3. 返回 growth 对象（含 hookText），供前端首页展示钩子

## 七、MVP 落地优先级（先跑通"诞生→孵化→破壳"）

1. **P0** pets 表加 container/rarity/hatchProgress/stage 枚举扩容 + pet_lottery 表
2. **P0** 砸蛋两接口 + 成长引擎接入 session/end（stage 真推进）
3. **P0** 首页 hookText 钩子文案（用后端字段，不写死）
4. **P1** 密码锁 lockSlots 拨动 + 2 转轮 7 张图
5. **P2** 加速道具、里程碑额外砸蛋机会、出生地多形态立绘
